# bank_operation

## Описание
Проект bank_operation - это приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение будет генерировать JSON-данные для веб-страниц, 
формировать Excel-отчеты, а также предоставлять другие сервисы 

## Установка
- [клонируйте репозиторий](https://github.com/AlexJharinov/Project_bank)

- запустите файлы для обработки данных 
```
python main.py

```


# Тестирование

- запустите файлы для тестирования модулей
```
python test_utils.py
python test_reports.py
python test_services.py

```
